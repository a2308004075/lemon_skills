# Lemon Checkpoints v1.2 提示词

请根据下面的材料生成测试执行清单。

默认以 Excel（.xlsx）交付：工作表顺序为执行看板、测试清单、待确认、规则证据、覆盖地图。仅当用户明确要求时再改用 Markdown 或脑图。

先说明业务背景和材料限制，再区分已确认事实、验证建议和待确认问题。待确认问题必须另外输出独立清单，写明关联测试点、风险、负责人、状态和确认结论，不能只藏在证据表或依据列。围绕用户完成目标的业务链路识别风险，把测试点分为首轮冒烟、重点验证和扩展检查。每条测试点写明触发情况、具体样本、可核对结果、证据级别、严重度、执行方式和失败影响。最后使用标准测试方向生成覆盖地图。

材料没有说明的规则不得自行确定。高风险但缺少依据的场景可以保留为验证建议，并关联待确认问题。不要写逐步测试操作。
