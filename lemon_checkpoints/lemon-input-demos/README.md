# Lemon 六种需求输入 Demo

| 编号 | 输入方式 | 文件或目录 |
|---|---|---|
| 01 | 需求文本 | `01-requirement-text.txt` |
| 02 | 本地需求文档 | `02-requirement-document.md` |
| 03 | 页面截图 | `03-login-page-screenshot.png` |
| 04 | 产品原型 | `04-login-prototype.html` |
| 05 | 接口资料 | `05-openapi.yaml` |
| 06 | 多材料组合 | `06-multi-source-package/` |

HTML是当前开发中常用、可直接在浏览器运行的交互原型格式。多材料组合包通过`manifest.md`说明材料角色和合并规则。
