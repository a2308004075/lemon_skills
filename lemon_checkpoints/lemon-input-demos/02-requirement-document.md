# 智汇ERP V3.5 登录与租户注册需求

## 1. 背景

用户通过统一登录页完成身份认证，成功后进入统计首页。新用户可以从登录页进入租户注册流程。本文件用于验证 Lemon 对结构化需求文档的读取、规则提取和待确认识别能力。

## 2. 页面范围

| 控件 | 要求 |
|---|---|
| 用户名 | 登录必填，不限制长度和字符类型 |
| 密码 | 登录必填，不限制长度和字符类型，区分大小写 |
| 验证码 | 必填，右侧显示验证码图片 |
| 记住密码 | 可选，当前实现存在明文存储风险 |
| 注册租户 | 进入租户注册流程 |
| 登录 | 提交认证请求 |

## 3. 业务规则

### 3.1 登录

- 登录成功后进入统计首页。
- HTTP状态码为`200`时仍需判断响应中的`msgTip`，不能只根据HTTP状态判断成功。
- 登录用户名是否区分大小写取决于数据库配置，目前没有统一结论。

### 3.2 验证码

- 正常生成4位数字或小写字母。
- 校验不区分大小写，有效期2分钟。
- 点击图片刷新验证码。
- 每次提交校验后验证码都会被消费，不论正确或错误。
- 刷新后旧验证码不会立即删除，在自身有效期内仍可能使用。
- 源码存在通用验证码测试分支，需要删除或在生产环境彻底关闭。

### 3.3 会话

- 服务端会话有效期3天，访问时续期。
- 前端Token缓存7天，与服务端有效期不一致。
- 支持同一账号在不同设备同时登录。
- 退出只清除当前设备的当前会话。

### 3.4 记住密码

当前实现把用户名和明文密码写入`localStorage`，没有过期时间。正常退出不会清除；取消勾选并再次提交登录后才删除。该行为属于安全缺陷，不作为正常验收标准。

### 3.5 注册

- 用户名至少4位且包含小写字母。
- 密码至少6位且同时包含小写字母和数字。
- 密码区分大小写。

## 4. 接口与错误码

统一前缀：`/jshERP-boot`

| 能力 | 路径 | 关键结果 |
|---|---|---|
| 登录 | `/user/login` | 同时判断HTTP状态和`msgTip` |
| 注册 | `/user/registerUser` | 用户名重复返回`500003` |
| 验证码 | `/user/randomImage` | 生成验证码图片及关联标识 |
| 退出 | `/user/logout` | 只清除当前会话 |

验证码错误、失效、为空分别返回`500010`、`500011`、`500012`。

## 5. 已知风险

1. 未发现登录注册专用限流或失败锁定。
2. `localStorage`长期保存明文密码。
3. 源码存在通用验证码测试分支。
4. 前后端会话有效期不一致。
5. 除成功登录外，认证审计记录不完整。

## 6. 待确认

1. 登录用户名是否区分大小写。
2. 页面加载和登录接口的性能验收指标。
3. V3.5相对上一版本的具体变更范围。
